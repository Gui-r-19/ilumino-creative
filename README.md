# Ilumino Creative — versão base

Abra `index.html` no navegador ou publique esta pasta como site estático. Não há instalação ou processo de compilação. As fontes usam Google Fonts; quando indisponíveis, o navegador usa fontes locais.

## O que editar

- `content.js`: serviços, etapas, perguntas frequentes, opções do briefing e WhatsApp.
- `index.html`: chamadas principais, seções e metadados.
- `styles.css`: cores, tipografia, espaçamento, responsividade e animação.
- `refinement.css`: acabamento minimalista, iluminação ambiente e ícones. Ajuste este arquivo para evoluir a direção atual.
- `app.js`: navegação, resumo, cópia e futura abertura do WhatsApp.

Para ativar o WhatsApp, preencha `whatsapp` em `content.js` com o número real, incluindo código do país e DDD, somente dígitos. Exemplo de formato: 55 + DDD + número. Quando configurado, o botão muda automaticamente para “Continuar no WhatsApp”. A mensagem abre para revisão; o visitante confirma o envio.

Sem número configurado, o briefing é copiado localmente. Se o navegador bloquear a cópia, aparece uma caixa com o resumo para copiar manualmente. Nenhum lead é armazenado ou enviado a um servidor.
